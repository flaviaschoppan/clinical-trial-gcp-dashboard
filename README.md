# Clinical Trial Safety & GCP Dashboard

A Python-based project under development to simulate clinical trial data and explore safety monitoring, adverse event reporting, site performance, and data quality in the context of Good Clinical Practice (GCP).

The project will use synthetic datasets and is intended for educational and portfolio purposes. It does not represent real clinical trial data or a validated clinical monitoring system.

## Planned Technology Stack

- Python
- pandas and NumPy
- Streamlit
- Plotly

## Project Status

**In development.** Initial repository structure and dependencies are being established.
